ВЕЛЕС — предварительный калькулятор строительства дома

Рабочая демоверсия для менеджера: ручной ввод параметров дома,
выбор комплектации, редактируемый прайс и предварительное КП.

ЗАПУСК
Откройте «Велес — калькулятор.html» в обычном браузере.
Файл содержит все стили и код; установка зависимостей не нужна.
Для работы с исходниками: python3 -m http.server 8766 --directory dist
Затем откройте http://localhost:8766/

РАЗРАБОТКА
Исходники: dist/index.html, dist/style.css, dist/app.js, dist/model.mjs.
Проверки: npm test (или node test.mjs).
Сборка автономного HTML после изменений: npm run build.
Node.js требуется только для тестов и сборки, внешних npm-зависимостей нет.

ОГРАНИЧЕНИЯ ДЕМОВЕРСИИ
Ставки перенесены из прежнего бота; их актуальность и включение прибыли
требуют подтверждения. Дополнительная наценка компании и партнёра
пока не реализована. Итог не является достоверной себестоимостью.
Если не заданы ставки или объёмы, показана только учтённая часть стоимости.
Геометрические коэффициенты — предварительная оценка, не обмер проекта.
Калькулятор не заменяет конструктивный расчёт инженера.
Доставка зависит от расстояния только при заданных условиях и тарифе.
Сохранение клиентов и расчётов не реализовано: после перезагрузки
введённые данные теряются. Прайс редактируется только на текущий сеанс.
Распознавание планов нейросетью не подключено.
Печать КП доступна после подтверждения прайса и комплектации.
PDF сохраняется через стандартное окно печати браузера.

и не публикуйте приложение без отдельного согласования владельца.
